# Contributing to Obsync

Thank you for your interest in contributing to **Obsync**! We welcome bug reports, feature requests, documentation improvements, and pull requests.

## How to Contribute

1. **Reporting Bugs**:
   - Check existing issues before opening a new one.
   - Include clear reproduction steps, environment details (Obsidian version, OS), and logs/screenshots where possible.

2. **Suggesting Enhancements**:
   - Open an issue describing the proposed feature and why it benefits the Obsidian ecosystem.

3. **Submitting Pull Requests**:
   - Fork the repository and create a new feature branch.
   - Run `npm run typecheck` and `npm run build` to verify that the build succeeds without errors.
   - Open a pull request with a descriptive title and summary of changes.

## Development Guidelines

- Write clean, well-typed TypeScript.
- Maintain compatibility with standard Obsidian Plugin API guidelines.
- Follow ESLint and formatting standards.
