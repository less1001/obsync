# Security Policy

## Supported Versions

We actively support and provide security updates for the latest major/minor releases of **Obsync**:

| Version | Supported          |
| ------- | ------------------ |
| 0.4.x   | :white_check_mark: |
| < 0.4.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Obsync:

1. Please **do not** report security vulnerabilities via public GitHub issues.
2. Please open a private security advisory on GitHub or email the maintainer directly.
3. Provide detailed steps to reproduce the issue and any potential impact analysis.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to release a patch promptly.
