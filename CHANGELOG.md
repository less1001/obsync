# Changelog

All notable changes to the **Obsync** Obsidian plugin will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.4.10] - 2026-07-14

### Added
- Migrated sync endpoints to robust `/v2/sync` protocol with multi-device acknowledgment.
- Enhanced image localization path formatting and space-character URL decoding.
- Added funding sponsorship links.

## [0.4.9] - 2026-07-11

### Fixed
- Fixed URL encoding for space characters in localized image links.

## [0.4.8] - 2026-07-11

### Added
- Simplified image folder directory paths.
- Added smart antivirus warning toast for smoother mobile sync.

## [0.4.0] - 2026-07-02

### Added
- Full WeChat Official Account rich article Markdown parsing.
- Direct memos, quotes, and quick text sync to local Obsidian vault.
- Status bar sync indicator and manual sync command.
